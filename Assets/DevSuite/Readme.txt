========================================================================
                      DevSuite - Unity Developer Toolbox
========================================================================
Thank you for using DevSuite! Below is a quick setup guide for each of the
5 integrated tools.

------------------------------------------------------------------------
1. DevSuite Dashboard
------------------------------------------------------------------------
Open the main hub via:
Menu: Tools -> DevSuite -> Dashboard

This is the unified control center where you can manage and configure all
tools in one place.

------------------------------------------------------------------------
2. Project Window+
------------------------------------------------------------------------
- Color code folder icons based on custom rules (e.g., Prefabs, Materials).
- Displays exact file sizes directly next to assets in the Project view.
- Shows reference count badges to identify unused assets.
- Clean empty folders instantly from the dashboard.

------------------------------------------------------------------------
3. Hierarchy Organizer
------------------------------------------------------------------------
- Turn empty GameObjects into clean, full-width category dividers (headers)
  using formatting rules (e.g., prefixing GameObject names with "---").
- Set custom font styles, alignments, text colors, and background colors.
- Adds toggle checkboxes directly in the Hierarchy list to quickly enable
  or disable GameObjects.

------------------------------------------------------------------------
4. Scene Notes & Kanban Board
------------------------------------------------------------------------
- Hover over any GameObject in the Scene view and press [Shift + N] to 
  drop a 3D sticky note.
- Move notes between TO DO, IN PROGRESS, and DONE status columns in the
  dashboard's Kanban tab.
- Click "Go To" on any task card to instantly focus the scene camera.

------------------------------------------------------------------------
5. Project Doctor
------------------------------------------------------------------------
- Scan your scene for missing scripts (Null references) and unassigned
  UI events (empty Button onClick events).
- One-click auto-fixes to clean up missing components or remove empty 
  event listeners.

------------------------------------------------------------------------
6. Command Palette
------------------------------------------------------------------------
- Press [Ctrl + Shift + Alt + P] to open the global search overlay.
- Quickly search and run actions, or execute batch helper macros like:
  * Grouping selected GameObjects
  * Aligning/snapping objects down to the ground
  * Batch renaming multiple assets
